# Portal 繁體中文／英文

建置時在固定的官方 Portal 原始碼版本上套用本機翻譯，不需要翻譯 API，也不會上傳介面或管理資料。

- `zh-TW.json`：翻譯字典；英文原文作為鍵值，也是英文介面與未知詞條的備援文字。
- `runtime.tsx`：語言選擇器、文字插值、基本錯誤翻譯與語言偏好。預設 `zh-TW`，使用與 SBOMScan 相同的 `app_language` localStorage key；不同網頁來源的偏好仍各自保存。
- `transform.mjs`：使用 TypeScript AST 辨識顯示文字，保留 API 路徑、權限代碼、型別、表單值及使用者資料。發現未翻譯的詞條會讓建置失敗。
- `install.mjs`：安裝語言控制項並設定日期、日曆與表單錯誤顯示。
- `test.mjs`：檢查字典插值、預設／英文／未知語言、錯誤顯示，以及顯示文字與 API 資料的轉換邊界。

語言切換位於「設定 → 一般 → 管理介面」的「語言」欄位，登入與其他頁面不顯示浮動選單。切換會重新載入目前頁面，保留目前網址、登入工作階段及語言偏好；請先儲存正在編輯的表單。既有產品名稱、方案名稱、License Key、ID、事件代碼與程式碼範例保留原值。未知的伺服器診斷訊息保留原文，避免誤譯錯誤細節。

`../portal-customize.mjs` 會在翻譯前將登入頁的電子郵件與密碼合併為同一份表單。管理員可使用 `admin` 別名或原電子郵件；登入沿用官方 Token API、記住登入、OTP 與 SSO 處理。升級上游時，請確認帳密同頁、錯誤訊息、驗證碼及登入後導向仍正常。

自架管理端移除價格連結、升級推廣與遮罩。CE 不支援的權限表單區塊、分析圖表不顯示，事件／請求紀錄則顯示不可用說明。既有版本判斷與 API 權限檢查保留。

修改字典後執行：

```powershell
docker compose build portal
docker compose up -d --no-deps portal
```

建置包含翻譯測試、TypeScript 檢查與 Vite 正式建置。若升級官方原始碼版本，需重新檢查 AST 轉換、整合點與所有新詞條，再以瀏覽器驗證兩種語言及主要表單。
